eryn

Mention @eryn in a server and it opens a thread, works the request through an agent, and streams the answer back. Reply in the thread and it keeps going.

Threads, not tabs

Each request gets a thread with a persistent session, so follow-ups carry the context instead of starting over.

Your models, your bill

Connect your own inference provider and pick the model per server. The server pays for its own inference.

Tools that do the work

A virtual filesystem, a sandboxed shell, Discord itself, and any external MCP server an admin links.

Commands

Everything is a slash command.

There is no dashboard. Configuration needs Manage Server, while stopping a run and reading help are open to everyone.

/eryn setup

Connect a provider, choose a model, and link MCP servers.

Manage Server
/eryn stop

Stop the run in the current thread. The session stays intact for the next message.

Everyone
/eryn help

Show the commands and point to where setup lives.
